## SPEC
```kotlin
package com.localnote.app.input
data class StrokeConfig(val colorArgb: Int, val widthPt: Float, val isHighlighter: Boolean)
```
`StrokeBuilder` exactly as ARCHITECTURE 8 (constructor `(config: StrokeConfig, minDistPt: Float = Constants.MIN_POINT_DIST_PT)`; methods `begin`, `add`, `end`, `snapshotPoints`). `add` drops a point if its distance to the LAST KEPT point is `< minDistPt`; `end` always appends the final point unless it is identical in x and y to the last kept point (then it only updates nothing and keeps the list). `end` returns `Stroke(newId(), points, config.colorArgb, config.widthPt, config.isHighlighter)`. Calling `end` without `begin` returns null.

`PageCanvasView` additions:
```kotlin
var strokeConfig: StrokeConfig = StrokeConfig(Constants.INK_PALETTE_ARGB[0], Constants.PEN_WIDTHS_PT[Constants.DEFAULT_PEN_WIDTH_INDEX], false)
var onStrokeFinished: ((Stroke) -> Unit)? = null
```
Input rules in `onTouchEvent` (D24):
- On `ACTION_DOWN` read `toolType = e.getToolType(0)`. If `TOOL_TYPE_STYLUS` or `TOOL_TYPE_MOUSE`: enter DRAWING mode: remember `drawPointerId = e.getPointerId(0)`, create a `StrokeBuilder(strokeConfig)`, convert coordinates with `transform.screenToPage`, call `begin`. Otherwise use the existing pan/zoom behavior.
- In DRAWING mode: `ACTION_MOVE`: `idx = e.findPointerIndex(drawPointerId)`; if `idx < 0` ignore. For each `h in 0 until e.historySize` call `add` with historical x/y/pressure/time for that pointer, then `add` the current sample. Then `invalidate()`.
- `ACTION_UP`: add the final sample via `end(...)`; if the result is non-null call `onStrokeFinished`. Leave DRAWING mode. Run the bitmap-refresh logic only if the transform changed (it did not).
- `ACTION_CANCEL`: discard the builder, leave DRAWING mode, `invalidate()`.
- `ACTION_POINTER_DOWN`/`ACTION_POINTER_UP` while DRAWING: ignore completely (do not pan or zoom).
- Finger events never create strokes.
- Live stroke drawing: after committed strokes, if DRAWING draw `Stroke("live", builder.snapshotPoints(), cfg.colorArgb, cfg.widthPt, cfg.isHighlighter)` with `strokeRenderer`.

`EditorState` add:
```kotlin
fun addStrokeDirect(stroke: Stroke)   // temporary: replaces the current page with elements + stroke; updates project; main thread
```
`EditorScreen`: in the `AndroidView` `update` block set `view.strokeConfig` (use the constants default config for now) and `view.onStrokeFinished = { state.addStrokeDirect(it) }`. The next `setPage(...)` call (same page id) only refreshes elements.
