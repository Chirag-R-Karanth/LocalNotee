## SPEC
```kotlin
class StrokeRenderer {
    /** Draws [stroke] using transform [t]. */
    fun draw(canvas: Canvas, stroke: Stroke, t: ViewTransform)
}
```
Reuse two `Paint` instances (antialias on, style STROKE, cap ROUND, join ROUND) as fields. Convert each point with `t.pageToScreen`.
- `factor(p) = Constants.PRESSURE_MIN_FACTOR + Constants.PRESSURE_RANGE * p.coerceIn(0f, 1f)`.
- Pen (not highlighter), 2+ points: for each consecutive pair draw `drawLine`; `strokeWidth = max(1f, stroke.widthPt * t.scale * factor((p0.pressure + p1.pressure) / 2))`; color `stroke.colorArgb`.
- Pen, 1 point: fill a circle at the point, radius `max(0.5f, stroke.widthPt * t.scale * factor(p) / 2)`, style FILL.
- Highlighter, 2+ points: ONE `Path` (`moveTo`, `lineTo` for the rest) with `strokeWidth = max(1f, stroke.widthPt * t.scale)`, color = `stroke.colorArgb` with alpha replaced by `(Constants.HIGHLIGHTER_ALPHA * 255).roundToInt()`.
- Highlighter, 1 point: filled circle radius `stroke.widthPt * t.scale / 2` with the same alpha color.

`PageCanvasView`: add field `private val strokeRenderer = StrokeRenderer()`. In `onDraw`, after the page bitmap, loop `page.elements.filterIsInstance<Stroke>()` in list order and call `strokeRenderer.draw(canvas, s, transform)`. Clip the canvas to the page rect before drawing strokes (`canvas.save(); canvas.clipRect(pageRect); ...; canvas.restore()`).
