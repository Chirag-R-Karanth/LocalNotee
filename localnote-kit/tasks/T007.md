# T007: Page renderer

PHASE: 1
DEPENDS ON: T006 DONE
READ: ARCHITECTURE 5, 6; DECISIONS D12, D15; API_CHEATSHEET B, I; TROUBLESHOOTING (PdfRenderer rows)

## GOAL
`PageRenderer` produces a white-backed bitmap for any page (PDF page or blank template) at a requested pixel width, with an LRU cache and stale-request dropping.

## FILES
Create:
- `app/src/main/java/com/localnote/app/render/PageRenderer.kt`
Forbidden: all else.

## SPEC
```kotlin
class PageRenderer(private val sourcePdf: java.io.File?, private val logger: Logger) {
    /** Asynchronous. [callback] runs on the main thread with the bitmap, or null on failure. If a newer render() call arrives before this one starts or finishes, this callback is NOT invoked. */
    fun render(page: Page, widthPx: Int, callback: (Bitmap?) -> Unit)
    /** Releases the PdfRenderer and clears the cache. Safe to call twice. */
    fun close()
}
```
Rules:
- One `Executors.newSingleThreadExecutor()`; all `PdfRenderer` calls on it. Open the `PdfRenderer` lazily on first PDF page request. If `sourcePdf` is null and the page is `PageKind.Pdf`: deliver null and log.
- Request id: `AtomicInteger`; `render` increments and captures; the task returns early if `captured != latest.get()` at start and does not deliver if it changed by the end.
- `widthPx` normalized: `bucket = Constants.BITMAP_WIDTH_BUCKET_PX`; `w = max(bucket, ceil(widthPx / bucket) * bucket)`. `heightPx = round(w * page.kind.heightPt / page.kind.widthPt)`.
- Cache: `android.util.LruCache<String, Bitmap>` keyed `"${page.id}@$w"`, max size in bytes = `Runtime.getRuntime().maxMemory() / 8`, `sizeOf = byteCount`. Cache hit delivers via `main.post` (still respecting the stale rule).
- PDF page: bitmap ARGB_8888, `eraseColor(Color.WHITE)`, `page.render(bmp, null, null, RENDER_MODE_FOR_DISPLAY)` for the source index, `openPage` always closed in `finally`.
- Blank page: bitmap white; `scale = w / widthPt`; draw by template using constants from `Constants`:
  - PLAIN: nothing.
  - RULED: horizontal lines at `y = RULED_TOP_PT + k * RULED_SPACING_PT` while `< heightPt`, color `RULED_COLOR`, stroke `1f` px.
  - DOT: dots radius `DOT_RADIUS_PT * scale` at every `DOT_SPACING_PT` in x and y (start at one spacing from the edges), color `DOT_COLOR`.
  - GRAPH: vertical and horizontal lines every `GRAPH_SPACING_PT`, color `GRAPH_COLOR`, stroke `max(1f, GRAPH_LINE_PT * scale)`.
- Catch `Throwable` in the task: log with `logger.e`, deliver null (but see stale rule). Catch `OutOfMemoryError` the same way.
