## SPEC
```kotlin
class ProjectWriter(
    private val store: ProjectStore,
    private val projectId: String,
    private val logger: Logger,
    private val onDurable: () -> Unit = {},
    private val onError: () -> Unit = {},
) {
    /** Queues: append [opJson] line to the journal. After every Constants.COMPACT_EVERY_OPS-th op also queues a snapshot of [projectAfterOp]. */
    fun onOp(opJson: String, projectAfterOp: Project)
    /** Queues a snapshot (store.writeSnapshot). */
    fun compact(project: Project)
    /** Blocks until everything queued so far has run. */
    fun flushBlocking()
    /** flushBlocking then stops the executor. Further calls are ignored. */
    fun shutdown()
}
```
- One `Executors.newSingleThreadExecutor()` inside. Everything runs on it, in order.
- Append: `FileOutputStream(store.journalFile(projectId), true)` write `line + "\n"` UTF-8, `flush`, `fd.sync` (API_CHEATSHEET F). On success call `onDurable()` (on the executor thread). On `IOException`: `logger.e(...)` and `onError()`.
- Compaction: `store.writeSnapshot(project)`; success -> `onDurable()`, failure -> log + `onError()`.
- Op counter is per writer instance. Counter resets after each compaction (including ones queued by `compact`).
- `flushBlocking` = submit a no-op task and `get()` its future.

`EditorState`:
```kotlin
fun attachWriter(w: ProjectWriter)
```
`dispatch`, `undo`, `redo` each, after updating `project`, call `writer?.onOp(commandJson, project)` where `commandJson` is `cmd.toJournalJson()` for dispatch, and the command RETURNED by `UndoStack.undo/redo` for those (D19). Do not call the writer when there is no writer.

`EditorScreen`: after a successful load create `ProjectWriter(store, projectId, logger, onDurable = {}, onError = {})` (callbacks wired in T016) and `state.attachWriter(...)`. When the screen leaves composition (`DisposableEffect` onDispose): `writer.compact(state.project)` (if non-null) then `writer.shutdown()`.
