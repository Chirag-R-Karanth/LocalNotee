## SPEC

### EditorState
```kotlin
class EditorState(val projectId: String) {
    var project: Project? by mutableStateOf(null); private set
    var pageIndex: Int by mutableStateOf(0); private set
    var loadFailed: Boolean by mutableStateOf(false); private set
    val currentPage: Page? get() = project?.pages?.getOrNull(pageIndex)
    fun load(services: Services, onDone: () -> Unit = {})   // loads on services.io, posts result to main
    fun goTo(index: Int)                                     // coerces into valid range
    fun next(); fun prev()
}
```

### EditorScreen(projectId)
- `val state = remember(projectId) { EditorState(projectId) }`; `LaunchedEffect(projectId) { state.load(services) }`.
- Renderer: `remember(state.project?.id) { PageRenderer(if (hasSourcePdf) store.sourcePdfFile(id) else null, logger) }` created after load; `DisposableEffect` closes it.
- Layout: `Scaffold` with top bar (DESIGN_SPEC 3.2: back arrow `Icons.AutoMirrored.Filled.ArrowBack` -> `appState.backToLibrary()`, title one line, page indicator text `page_indicator` formatted `(pageIndex+1, pageCount)`; the overflow menu is NOT shown). Body: `AndroidView(factory = { PageCanvasView(it) }, update = { it.setPage(state.currentPage, renderer, deskColor().toArgb(), pageShadowColor().toArgb()) })` filling the space.
- Prev/next: two 40 dp circular `IconButton`s overlaid at the left and right edges, vertically centered (text glyphs `‹` and `›`, `headlineMedium` style), alpha 0.6, disabled on first/last page.
- Page indicator click opens `AlertDialog` with a numeric `OutlinedTextField` (`goto_page_hint`) and buttons `action_ok`/`action_cancel`. Invalid or out-of-range input is coerced into range; empty input = no change.
- If `loadFailed`: Snackbar `error_open_failed` then `appState.backToLibrary()`.
