## SPEC
- `LibraryScreen` gets `val app = context.applicationContext as LocalNoteApp`; uses `app.services` and `app.appState`.
- State: `var items by remember { mutableStateOf(emptyList<ProjectMeta>()) }`. Load with `LaunchedEffect(app.appState.libraryVersion)` that runs `store.listMeta()` on a background executor and posts the result to main (API_CHEATSHEET I). One shared `Executors.newSingleThreadExecutor()` held in `Services` as `val io: java.util.concurrent.ExecutorService` (add it to `Services.kt`; allowed edit).
- Grid: `LazyVerticalGrid(columns = GridCells.Adaptive(minSize = 160.dp))` with 12 dp spacing and 16 dp content padding. Card per DESIGN_SPEC 3.1 (`ProjectCard`): 3:4 area (`surfaceVariant` color, 12 dp radius) showing the title's first character uppercased centered in `displayMedium` style, title one line ellipsis, subtitle `pluralStringResource(R.plurals.pages_count, n, n)` + " · " + `DateUtils.getRelativeTimeSpanString(updatedAt, System.currentTimeMillis(), DateUtils.MINUTE_IN_MILLIS).toString()`.
- `combinedClickable(onClick = open, onLongClick = askDelete)` on the card (needs `@OptIn(ExperimentalFoundationApi::class)`).
- FAB `Icons.Default.Add`. Tap opens a `DropdownMenu` with two items `action_import_pdf`, `action_new_notebook`.
- Import: `rememberLauncherForActivityResult(ActivityResultContracts.OpenDocument())`; on uri != null run `importer.import(uri)` on `io`; success -> main: `appState.bumpLibrary()` then `appState.openEditor(project.id)`; failure -> Snackbar `error_import_failed`.
- New notebook: on `io` build `Project(newId(), default title, now, now, false, listOf(Page(newId(), PageKind.Blank(Template.PLAIN, Constants.DEFAULT_PAGE_WIDTH_PT, Constants.DEFAULT_PAGE_HEIGHT_PT), emptyList())))`, `store.create`, then same success path.
- Delete: `AlertDialog` with texts `delete_title`, `delete_message` (format with title), buttons `action_cancel`, `action_delete`. On confirm: `store.delete(id)` on `io`, then `bumpLibrary()`.
- Empty state: when `items` is empty show the centered texts from T002 instead of the grid.
- Snackbar via `Scaffold(snackbarHost)` and `rememberCoroutineScope` (API_CHEATSHEET H).
