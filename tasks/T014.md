# T014: Eraser and undo/redo UI

PHASE: 2
DEPENDS ON: T013 DONE

## GOAL
Eraser tool removes whole strokes it touches (one undoable action per gesture). Top bar gets undo and redo buttons.

## FILES

Modify:
- `app/src/main/java/com/localnote/app/ui/editor/PageCanvasView.kt`

- `app/src/main/java/com/localnote/app/ui/editor/EditorScreen.kt`

## SPEC
```kotlin
object EraserHitTest {
    /** True if any segment of [stroke] is within radiusPt + stroke.widthPt/2 of (x, y). A 1-point stroke is a zero-length segment. */
    fun hit(stroke: Stroke, x: Float, y: Float, radiusPt: Float): Boolean
}
```
Use point-to-segment distance (clamp projection to the segment).

`PageCanvasView`:
- `var onErase: ((List<String>) -> Unit)? = null`.
- When `tool == Tool.ERASER` and the pointer is STYLUS or MOUSE: enter ERASING mode on `ACTION_DOWN`. For every sample (historical then current, in page coordinates) test all strokes of the current page with `EraserHitTest.hit(stroke, x, y, Constants.ERASER_RADIUS_PT)`; add hit ids to a `LinkedHashSet<String> erasedPreview`. Strokes in `erasedPreview` are NOT drawn (preview). `invalidate()` on change.
- `ACTION_UP`: call `onErase(erasedPreview.toList())` if non-empty; clear the set; leave ERASING. `ACTION_CANCEL`: clear the set without calling. Pointer-down/up of other pointers ignored while ERASING.
- Remove the T012 rule that ignores eraser input.

`EditorState`:
```kotlin
fun eraseIds(ids: List<String>)   // builds RemoveElements(page.id, removed) where removed = (index, element) for each current-page element whose id is in ids, ascending by index; dispatches it; no-op if removed is empty
```
`EditorScreen`: `view.onErase = { ids -> state.eraseIds(ids) }`. Top bar: add two buttons before the page indicator using text glyphs `↶` (undo, content description `action_undo`) and `↷` (redo, `action_redo`), 48 dp, `titleLarge` style; `enabled = state.canUndo` / `state.canRedo` with alpha 0.38 when disabled; actions `state.undo()` / `state.redo()`.

## TESTS (required, `EraserHitTestTest`)
- `hits when pointer is on a segment`
- `misses when pointer is beyond radius plus half width`
- `hits a single point stroke`
- `stroke width extends the hit area`
- `hits near segment end but not past radius`
