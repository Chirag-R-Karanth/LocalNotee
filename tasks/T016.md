# T016: Autosave lifecycle and Saved label

PHASE: 2
DEPENDS ON: T015 DONE
READ: DESIGN_SPEC 3.2 ("Saved" label), 4; DECISIONS D21, D28; API_CHEATSHEET H, I

## GOAL
Compaction on app stop, a subtle "Saved" label, and a Snackbar if saving fails.

## FILES
Modify:
- `app/src/main/java/com/localnote/app/AppState.kt` (add `var stopHook: (() -> Unit)? = null` as a PLAIN property, not Compose state)
- `app/src/main/java/com/localnote/app/MainActivity.kt` (override `onStop()`: call `super.onStop()` then `(application as LocalNoteApp).appState.stopHook?.invoke()`)
- `app/src/main/java/com/localnote/app/ui/editor/EditorState.kt`
- `app/src/main/java/com/localnote/app/ui/editor/EditorScreen.kt`

## SPEC
`EditorState` add:
```kotlin
var savedVisible: Boolean by mutableStateOf(false); private set
var saveError: Boolean by mutableStateOf(false); private set
fun markSaved()          // main thread: savedVisible = true; cancel pending hide; post hide after Constants.SAVED_LABEL_MS via Handler(Looper.getMainLooper())
fun markSaveError()      // main thread: saveError = true
fun clearSaveError()
fun saveNow()            // writer?.compact(project); writer?.flushBlocking()   (documented exception: brief main-thread wait in onStop)
```
`EditorScreen`:
- Create the writer with `onDurable = { mainHandler.post { state.markSaved() } }` and `onError = { mainHandler.post { state.markSaveError() } }`.
- `DisposableEffect(state)`: `appState.stopHook = { state.saveNow() }`; onDispose: `appState.stopHook = null` (before the compact/shutdown from T015).
- Top bar title area: a `Column` with the title (one line) and below it `Text(stringResource(R.string.status_saved), style = labelSmall, color = onSurfaceVariant, modifier = Modifier.alpha(animateFloatAsState(if (state.savedVisible) 1f else 0f, tween(300)).value))`. The label always occupies its space (no layout shift).
- `LaunchedEffect(state.saveError)`: when true show Snackbar `error_save_failed`, then `state.clearSaveError()`.
