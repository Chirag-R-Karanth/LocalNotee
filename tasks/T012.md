# T012: Tool state and toolbar

PHASE: 2
DEPENDS ON: T011 DONE
READ: DESIGN_SPEC 2, 3.2, 4, 5; DECISIONS D30; ARCHITECTURE 1

## GOAL
Floating bottom toolbar: choose pen, highlighter, eraser; choose color; choose width. Pen and highlighter use the selection. Eraser does nothing yet.

## SPEC
`Tool.kt`: `enum class Tool { PEN, HIGHLIGHTER, ERASER }`.

`EditorState` add observable fields (Compose `mutableStateOf`, private set) and setters:
```kotlin
var tool: Tool;            fun selectTool(t: Tool)
var colorIndex: Int = 0;   fun selectColor(i: Int)            // 0 until INK_PALETTE_ARGB.size
var penWidthIndex: Int = Constants.DEFAULT_PEN_WIDTH_INDEX;               fun selectPenWidth(i: Int)
var highlighterWidthIndex: Int = Constants.DEFAULT_HIGHLIGHTER_WIDTH_INDEX; fun selectHighlighterWidth(i: Int)
fun strokeConfig(): StrokeConfig   // PEN or ERASER -> (color, PEN_WIDTHS_PT[penWidthIndex], false); HIGHLIGHTER -> (color, HIGHLIGHTER_WIDTHS_PT[highlighterWidthIndex], true)
```
Default `tool = Tool.PEN`. Setters coerce indices into range.

`PageCanvasView`: add `var tool: Tool = Tool.PEN`. In DRAWING mode entry (T011 rule) enter drawing ONLY when `tool != Tool.ERASER`; with ERASER, stylus/mouse input is ignored (consumed, nothing happens).

`EditorToolbar(state: EditorState, modifier: Modifier)` composable (DESIGN_SPEC 3.2):
- `Surface(shape = RoundedCornerShape(28.dp), tonalElevation/shadowElevation 6.dp, color = MaterialTheme.colorScheme.surface)` containing a `Row` with 8 dp padding, items spaced 4 dp.
- Three 48 dp tool buttons with text glyphs (D30): pen `✎`, highlighter `▮`, eraser `⌫` (`headlineSmall` style). Content descriptions from `tool_pen`, `tool_highlighter`, `tool_eraser`. Selected tool: background circle 40 dp with `primary` at alpha 0.16, animated with `animateColorAsState(tween(120))`.
- A `VerticalDivider`-like 1 dp x 24 dp box between groups (use `Box` with background `outlineVariant`).
- Color button: 24 dp filled circle in the current color (a `Box` with `CircleShape` background). Tap opens a `DropdownMenu` whose content is a `Row` of the 8 palette circles (28 dp, 6 dp spacing); selected circle has a 2 dp `primary` border. Tap selects and closes.
- Width button: a 24 dp wide `Box` showing a horizontal bar of height `min(widthPt, 12).dp` with `onSurface` color for the current tool's width. Tap opens a `DropdownMenu` with a `Row` of 4 bars for that tool's presets; selected one gets the `primary` color. Disabled (alpha 0.38, not clickable) when tool is ERASER.
- Color button also disabled when tool is ERASER.

`EditorScreen`: place the toolbar in a `Box` overlay `Modifier.align(Alignment.BottomCenter).padding(bottom = 12.dp)`. In the `AndroidView` `update` block also set `view.tool = state.tool` and `view.strokeConfig = state.strokeConfig()`.
