# T001: Baseline checks and manifest settings

PHASE: 1
DEPENDS ON: human setup (HOW_TO_BUILD Part A) complete
READ: DECISIONS D05, D06, D07

## GOAL
Confirm the untouched baseline passes verification, then apply the three manifest settings. Record the template's versions in PROGRESS.

## FILES
Modify:
- `app/src/main/AndroidManifest.xml`
- `PROGRESS.md` (append LOG lines only)
Forbidden: everything else.

## SPEC
In `AndroidManifest.xml`:
1. On the `<application>` element set `android:allowBackup="false"` (change the existing value if present).
2. On the `<activity android:name=".MainActivity" ...>` element add:
   `android:configChanges="orientation|screenSize|screenLayout|smallestScreenSize|keyboardHidden|uiMode"`
3. Do NOT add any `<uses-permission>` element.
Leave every other attribute and element untouched.

## STEPS
1. Run `bash tools/verify.sh`. Must PASS (it is the baseline).
2. Edit the manifest as in SPEC.
3. Run `bash tools/verify.sh`. Must PASS.
4. Open `gradle/libs.versions.toml` (read only) and `app/build.gradle.kts` (read only). Append ONE line to `PROGRESS.md` LOG:
   `T001 info: agp=<value>, kotlin=<value>, composeBom=<value>, minSdk=<value>, compileSdk=<value>, targetSdk=<value>`
   (copy values exactly as written in those files; write `n/a` if not found).

## TESTS (required)
None (configuration only).

## VERIFY
`bash tools/verify.sh` -> `VERIFY: PASS`

## HUMAN CHECK
- Install and open the app on the device: still shows the template screen. Rotate the device: screen stays, no restart.

## DO NOT
- Touch Gradle files. Change any version. Add permissions.
