## SPEC
```kotlin
interface Command {
    fun apply(p: Project): Project
    /** [before] is the project state BEFORE apply. Returns the command that exactly reverses this one. */
    fun inverse(before: Project): Command
    fun toJournalJson(): String
}
class AddStroke(val pageId: String, val stroke: Stroke) : Command        // appends; journal = encodeAddStroke
class RemoveElements(val pageId: String, val removed: List<Pair<Int, Element>>) : Command   // removes by id; journal = encodeRemoveElements
class InsertElements(val pageId: String, val items: List<Pair<Int, Element>>) : Command     // inserts ascending by index; journal = encodeInsertElements
```
- `AddStroke.inverse(before)` = `RemoveElements(pageId, listOf(before page elements.size to stroke))`.
- `RemoveElements.inverse(before)` = `InsertElements(pageId, removed sorted ascending by index)`.
- `InsertElements.inverse(before)` = `RemoveElements(pageId, items)`.
- `InsertElements.apply`: for each item ascending by index, insert at `index.coerceAtMost(currentSize)`, skipping elements whose id already exists on the page. Unknown page: return project unchanged. Same unknown-page rule for all commands.
- `ProjectJson.encodeInsertElements(pageId, items): String` and `applyOp` support for op `"insert_elements"`: `{"op":"insert_elements","page":"..","items":[{"i":3,"e":{element json}}]}`; same insertion rules.

```kotlin
class UndoStack {
    fun push(cmd: Command, before: Project)       // computes and stores inverse now; clears redo
    fun canUndo(): Boolean
    fun canRedo(): Boolean
    /** Returns new project and the command that was applied (the stored inverse). Caller guarantees canUndo(). */
    fun undo(p: Project): Pair<Project, Command>
    /** Returns new project and the command that was applied (the original). Caller guarantees canRedo(). */
    fun redo(p: Project): Pair<Project, Command>
}
```
Internally an entry is `(cmd, inverse)`. undo applies `inverse`, moves the entry to the redo stack. redo applies `cmd`, moves the entry back.

`EditorState` add:
```kotlin
var undoVersion: Int by mutableStateOf(0); private set     // bump after every dispatch/undo/redo to trigger recomposition
fun dispatch(cmd: Command)    // before = project; project = cmd.apply(before).copy(updatedAt = System.currentTimeMillis()); undoStack.push(cmd, before); undoVersion++
fun undo(); fun redo()        // no-op if cannot; update project (+ updatedAt) and bump undoVersion
val canUndo: Boolean get()    // reads undoVersion so Compose observes it
val canRedo: Boolean get()
```
Remove `addStrokeDirect`. In `EditorScreen`: `view.onStrokeFinished = { s -> state.currentPage?.let { state.dispatch(AddStroke(it.id, s)) } }`.
