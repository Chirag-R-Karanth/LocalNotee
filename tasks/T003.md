## SPEC
Model classes: copy from ARCHITECTURE section 2 exactly, one concept per file as follows:

- `InkPoint.kt`: `InkPoint`

- `Page.kt`: `sealed interface PageKind` (with `Pdf` and `Blank`), `data class Page`
- `Project.kt`: `data class Project`

`ProjectJson.kt`:
```kotlin
object ProjectJson {
    fun encodeProject(p: Project): String
    fun decodeProject(s: String): Project                 // throws org.json.JSONException
    fun encodeElement(e: Element): org.json.JSONObject
    fun decodeElement(o: org.json.JSONObject): Element
    fun encodeAddStroke(pageId: String, stroke: Stroke): String       // one line, no newline
    fun encodeRemoveElements(pageId: String, ids: List<String>): String
    /** Applies one journal line. Unknown op, unknown page: returns [p] unchanged. Malformed JSON: throws JSONException. Idempotent per ARCHITECTURE 3. */
    fun applyOp(p: Project, line: String): Project
}
```
JSON shapes exactly as ARCHITECTURE section 3 (`"v":1`, `"kind":{"type":"pdf"|"blank",...}`, stroke `"pts"` arrays of 4 numbers, `"hl"`, `"color"`, `"width"`). Floats are written with `.toDouble()`. Template stored as `name`. `decodeProject` must reject `"v"` other than 1 by throwing `JSONException("unsupported version")`.
`add_stroke` appends the stroke at the END of the page's elements unless a stroke with that id exists.
