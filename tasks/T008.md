## SPEC

### ViewTransform (pure, no android imports)
```kotlin
data class ViewTransform(val scale: Float, val tx: Float, val ty: Float) {
    fun pageToScreen(x: Float, y: Float): Pair<Float, Float>      // x*scale+tx, y*scale+ty
    fun screenToPage(x: Float, y: Float): Pair<Float, Float>      // exact inverse
    fun panBy(dx: Float, dy: Float): ViewTransform
    fun zoomAround(focusX: Float, focusY: Float, factor: Float, minScale: Float, maxScale: Float): ViewTransform
    fun clamped(viewW: Float, viewH: Float, pageW: Float, pageH: Float): ViewTransform
    companion object { fun fitWidth(viewW: Float, pageW: Float): ViewTransform }
}
```
Semantics exactly as ARCHITECTURE section 7.

### PageCanvasView
```kotlin
class PageCanvasView(context: Context) : View(context) {
    fun setPage(page: Page?, renderer: PageRenderer?, deskColor: Int, shadowColor: Int)
}
```
- If `page?.id` equals the current page id: only store the new page object and `invalidate()` (keep transform and bitmap). Otherwise: reset to `fitWidth`, clear the current bitmap, request a new bitmap.
- Fit and limits: `fit = viewW / pageWidthPt`; `minScale = fit`; `maxScale = fit * Constants.MAX_ZOOM_FACTOR`. On size change (`onSizeChanged`) with a page set: refit.
- Gestures (Phase 1: every pointer type pans and zooms):
  - Pinch: `ScaleGestureDetector`; on scale call `zoomAround(focusX, focusY, scaleFactor, min, max)` then `clamped(...)`.
  - One-pointer drag: on `ACTION_MOVE` while not scaling, `panBy(dx, dy)` then `clamped(...)`. Track last x/y; reset tracking on `ACTION_DOWN`, `ACTION_POINTER_UP` (use the remaining pointer's position), and when scaling ends.
  - Return `true` from `onTouchEvent`; call `parent?.requestDisallowInterceptTouchEvent(true)` on `ACTION_DOWN`.
- Drawing order and look: ARCHITECTURE section 6 layers 1-3 (strokes later). Page shadow: fill a rect expanded by `3dp` on all sides and shifted `2dp` down with `shadowColor`. Page bitmap drawn with `Paint(Paint.FILTER_BITMAP_FLAG)` into the page rect via `canvas.drawBitmap(bmp, null, RectF, paint)`. If no bitmap yet draw a white rect.
- Bitmap requests: call `renderer.render(page, widthPx, cb)` when (a) a new page is set, (b) size changes, (c) a gesture ends (`ACTION_UP`/`ACTION_CANCEL` or scale end). `widthPx = clamp(round(pageWidthPt * scale), 1, MAX_BITMAP_WIDTH_FACTOR * viewWidth)`. In `cb`: if bitmap != null store it and `invalidate()`. During gestures keep drawing the previous bitmap stretched to the current rect.
